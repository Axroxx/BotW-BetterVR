ArrowShootMove Arc Viewer

This static page approximates the standard ArrowShootMove bow arc from the Wii U game code. It uses the phase split observed in IDA: a short normalized launch tick, a straight flight phase that integrates speed toward AimSpeed, and a fall phase that swaps in FallAccel, Gravity, and the native FallSpeedRatioByRange formula.

Fall-Phase Formula

fallAimSpeed + ((atRange / 20) - 1) * fallSpeedRatioByRange, clamped to [0, aimSpeed]. If abs(fallAccel) is effectively zero, the sim keeps the current speed and falls back to abs(gravity) only when that speed is near zero.

Range-Check Origin

m_39_checkFloat33WhetherAtRange measures from enterSub's stored mtxPos_CC, not necessarily from the visible launch origin. Leave the override off to reuse Launch Origin, or enable it when your real trace stays straight one sample longer than the sim.
